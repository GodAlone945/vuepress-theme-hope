02 / 武器穿盾：参数层分析

区分“护盾不拦截”、“穿透单位”、“护盾伤害高”和“炮弹生成单位”。

明确可疑：interceptedbyshieldtype = 0

这是武器与护盾拦截类型的关键参数。数值 0 不命中任何拦截类型掩码；在遵循该拦截规则的护盾下，弹体不会按普通拦截流程被拦住。

虫族崛起：ARM 蓝色指挥官狙击枪 old_armsnipe_weapon 明确写了 interceptedbyshieldtype=0，同时有 overpenetrate=true。

巴卡妮：部分 Raptor 尖刺弹武器显式为 interceptedbyshieldtype=0，规则模块也涉及对同类弹体设置此值。

不能直接断定穿盾的配置

interceptedbyshieldtype=1 / 4：意味着武器参与特定类型护盾的拦截，要和护盾的 shieldintercepttype 对照，不能单看数字判断。

overpenetrate=true：可能影响攻击贯穿单位的行为，但它本身不等于“无视护盾”。

damage.shields：代表对护盾的伤害数值，不是关闭拦截。

实验性全反弹 ≠ 无条件防御

两份模组都设置了 !experimentalshields bounceeverything。它修改符合条件的护盾碰撞/反弹行为，但不会凭空让本来不被该护盾拦截的武器获得拦截匹配。

实际结果还受游戏版本、护盾特性、弹体高度与生成逻辑影响。

女王投射生物容易造成误判

两份配置都使用带 customparams.spawns_name 等标记的弹体来生成单位。即使某个弹体本身被盾击中，后续单位生成、召唤行为的触发时机和位置也可能不同。

要判定是否“穿盾”，应分别记录：弹体是否被反弹、是否生成了单位、单位是否出现在护盾内部。仅凭配置文件无法证明这三步的运行时行为。

03 / 建议的游戏内验证

在同一张地图、同一种护盾、相同对手阵营下做对照测试。

测试目标记录指标判读重点
虫族崛起 ARM 狙击枪弹体是否直接击中盾后单位、盾能量是否减少对照 interceptedbyshieldtype=0
巴卡妮 Raptor 尖刺弹有盾/无盾伤害、弹体轨迹验证脚本强制设置的拦截类型
女王单位投射弹弹体碰撞坐标、生成单位坐标与数量区分“弹体穿盾”和“单位生成在盾内”
同武器改为拦截类型 1同一护盾下是否出现明显差异必须先确认目标护盾支持该类型

测试时请固定护盾倍率、实验盾模式、双方位置与游戏版本，避免把护盾被打空或地图地形影响误判为穿盾。
